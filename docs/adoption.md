# Adoption checklist

- [ ] Rename package, CLI and project metadata.
- [ ] Choose owner and license; retain attribution for any adapted material.
- [ ] Define behavior, API contracts and measurable acceptance criteria.
- [ ] Replace demo CLI and its test together.
- [ ] Set supported Python/platform matrix.
- [ ] Configure protected branches and required checks in GitHub.
- [ ] Add integration tests and explicit prerequisites.
- [ ] Pin dependency versions/lockfile once actual dependencies are chosen.
- [ ] Configure model/data provenance and artifact storage if relevant.
- [ ] Review skills and agent boundaries for your team's workflow.
- [ ] Run clean installation and validate a representative user workflow.
- [ ] Add release automation only after explicit human approval.
