# Provenance

Template code and prose are newly authored for this repository. The architecture
is informed by public LibreYOLO patterns listed in source-analysis.md. No model
implementation, weights, datasets, private prompts or hosted configuration is
copied. LibreYOLO is MIT licensed at the inspected revision.

For future adaptations record source URL, immutable revision, files, license,
modifications and required notices. Review code, weights and datasets separately.
The PR checker verifies a statement exists; it cannot establish its truth.
